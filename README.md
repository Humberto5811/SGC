# SGC - Sistema de Gestión de Contrataciones

Sistema para entidades del Estado Peruano basado en **Ley N° 32069**.

## 📋 Características

- ✅ 5 tipos de contratación (Bienes, Servicios, Locación, Licitación, Concurso)
- ✅ 30 requisitos funcionales
- ✅ Flujo completo: Requerimiento → DEC → Invitaciones → Cotizaciones → Contrato → Ejecución
- ✅ Firma digital y manual
- ✅ Integración con SIGAMEF y SIAF

## 🚀 Tecnologías

- HTML5/CSS3/JavaScript
- Bootstrap 5
- localStorage (prototipo)
- Chart.js
